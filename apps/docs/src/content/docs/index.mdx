GentleMail is an inbox for your team and an API for your code, on the same mailboxes. It runs as one Worker on your own Cloudflare account and serves every domain you connect to it.

## How it fits together

- **Domains.** Each domain you connect sends all its mail to your GentleMail through Cloudflare Email Routing, and sends through Cloudflare Email Service.
- **Mailboxes** are the addresses on those domains (`support@`, `invoices@`, `ada@`…). Create as many as you need; there's no per-seat price.
- **Users** sign in to the web app. Admins see every mailbox; everyone else sees the mailboxes they've been given.
- **Programs** use the same mailboxes through the [HTTP API](/docs/api/) with API keys, and hear about new mail through [webhooks](/docs/webhooks/).

Messages are stored in your own D1 database, and raw messages and attachments in your own R2 bucket. GentleMail reaches them through Worker bindings, so it never asks for a Cloudflare API token or account ID.

## What you need

- A **Cloudflare account on the Workers Paid plan** ($5/month), which includes the outbound email.
- A **domain whose DNS is on Cloudflare**, in the same account.
- A **GitHub account**, for the Deploy button.
